# Working in this sketchbook

The collection contains 24 native static SVGs and 24 five-second SVG loops. FORM lives separately in three/: full body, arm, hand, leg and foot. MUSE in expressions/ contains eight facial-expression studies of the same adult female character used by FORM. Both Three.js views have feature selection, labels and a guided camera.

- Preserve the accepted SVG collection and Hairline-inspired drawing language. Explicit Three.js requests use the separate 3D edition; no MP4 export is requested.
- Read the skill and inspect actual source/output before drawing changes. The historical skill identifier seven-second-storytelling remains, but its current duration is five seconds.
- Canonical files are corpus/svg/<id>.svg, corpus/animated/<id>.svg and corpus/hairline/*.json. Preserve accurate source IDs, prompts, methods and observations.
- Motion must visibly affect the requested expression, fingers, muscles or character action. The previous tiny tilts and color pulses were rejected. Use authored geometry and joint-aware articulation; preserve contacts and occlusion.
- Every animation track lasts five seconds with matched endpoint values. Do not use broad elastic distortion for major anatomical change.
- For SVGs, use actual native geometry with clean contours, quiet interiors and one focal accent. No embedded paintings, gradients, filters, grain or colored shadow masses. The explicit 3D edition uses licensed skinned GLB geometry, embedded PBR texture maps and soft studio lighting.
- Inspect stills, thumbnails, all authored extremes and actual SVG playback. Automated differences support visual review but do not certify artistic quality.
- Run compose, catalog, check, playback, visual review, verify, install-skill and bundle after full revisions. Refresh the catalog after review metadata changes. After local repairs run affected checks and refresh packaging. QA snapshots are internal evidence.
- README is generated by scripts/catalog.mjs. Keep the gallery, prompts, installed skill and archives coherent.
- Preserve prior editions in archive/. Source photographs remain in Downloads and are not redistributed. The anatomy is illustrative, not medically validated.
- For Three.js work, keep native model geometry, anatomical joint relationships and truthful region labels. Follow the source-backed explanation in three/SOURCES.md. Single absolute time drives motion; manual camera gestures interrupt guidance. Inspect all five scenes at rest, peak and intermediate poses, plus mobile, selection and camera behavior. Run build:three, catalog:three, check:three and bundle:three for changes to that edition.
- For MUSE, follow expressions/SOURCES.md and keep one identity with a shared neutral pose. Close eyelid apertures over the iris; attach lips and mouth cavity to the deforming facial surface. Inspect every expression from front, three-quarter and profile. Run catalog:expressions, check:expressions and playback:expressions, then refresh skill and combined bundle. The expression names describe authored acting poses.

- FORM and MUSE now share `three/character/character.mjs`, `materials.mjs`, and the CC0 assets documented in `three/character/assets/README.md`. Await `loadCharacter()` before cloning independent skeletons. Use `character/anatomy.mjs` and `expressions/character-face.mjs`; the earlier procedural models remain as historical source, not the default renderer. Preserve local license evidence and never copy upstream GPL generator code.
- Selection uses compact skinned surface regions and a posed CPU collision proxy. Update the source skeleton before the proxy, overlays and barycentric anchors. Test evaluated skin vertices, morph weights and bone matrices; raw rest-position buffers cannot verify skinned animation. Keep one fixed adult identity and a shared neutral across views.
- Portrait approval requires enlarged actual browser views with the face at least 450 pixels high, in addition to the gallery and mobile views. Inspect complexion, individual teeth, tongue depth and cheek normals there. A small contact sheet concealed previously rejected beard-like albedo patches, misplaced dental arches and a bright tongue filling the mouth.
