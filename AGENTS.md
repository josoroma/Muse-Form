# Working in this sketchbook

The current collection contains 24 native static SVGs and 24 clearly animated five-second SVG loops, with a gallery and reusable storytelling skill.

- Preserve the user's SVG-only delivery and Hairline-inspired drawing language. Do not create MP4s unless explicitly requested later.
- Read the skill and inspect actual source/output before drawing changes. The historical skill identifier seven-second-storytelling remains, but its current duration is five seconds.
- Canonical files are corpus/svg/<id>.svg, corpus/animated/<id>.svg and corpus/hairline/*.json. Preserve accurate source IDs, prompts, methods and observations.
- Motion must visibly affect the requested expression, fingers, muscles or character action. The previous tiny tilts and color pulses were rejected. Use authored geometry and joint-aware articulation; preserve contacts and occlusion.
- Every animation track lasts five seconds with matched endpoint values. Do not use broad elastic distortion for major anatomical change.
- Use actual native geometry with clean contours, quiet interiors and one focal accent. No embedded paintings, gradients, filters, grain or colored shadow masses.
- Inspect stills, thumbnails, all authored extremes and actual SVG playback. Automated differences support visual review but do not certify artistic quality.
- Run compose, catalog, check, verify, install-skill and bundle after full revisions. After local repairs run affected checks and refresh packaging. QA snapshots are internal evidence.
- README is generated by scripts/catalog.mjs. Keep the gallery, prompts, installed skill and archives coherent.
- Preserve prior editions in archive/. Source photographs remain in Downloads and are not redistributed. The anatomy is illustrative, not medically validated.
