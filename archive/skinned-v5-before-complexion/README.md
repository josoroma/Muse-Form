# Before complexion and oral-assembly repair

This source snapshot preserves the character, materials, facial contour, dental adapter, expression recipes, studio lighting, review records and selected renders before the clean complexion and oral-depth revision. It is not a standalone application. The unchanged licensed source GLBs and engine remain in the main project.

The later repair removes gray baked albedo mottling from the face, refines studio fill and facial contours, aligns both dental arches with the lip line, and seats the tongue deeper in the mouth. Earlier complete editions remain in the other archive directories.
