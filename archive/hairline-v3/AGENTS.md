# Working in this sketchbook

The current edition is a 24-study native SVG collection with seven-second animation, MP4 exports, a local gallery and the seven-second-storytelling skill.

- Read the skill and inspect the actual source/output before art changes. Preserve the user's native SVG preference and Hairline-inspired line discipline; Three.js is an option for necessary real 3D motion, not a requirement.
- Canonical files are corpus/svg/<id>.svg, corpus/animated/<id>.svg and corpus/hairline/*.json. Keep source IDs, prompts, actual construction methods and observations accurate.
- Use true native geometry. No raster images wrapped in SVG, gradients, filters, grain or colored shadow masses in this edition. Preserve believable anatomy, clean contours, occlusion and one focal accent.
- Prior editions are safely archived in archive/vector-v1 and archive/raster-v2. Current line drawings may use approved internal plates as construction references; do not claim that extracted contours were entirely drawn by hand.
- Source photographs stay in Downloads and are not redistributed. These artistic studies are not medically validated anatomy.
- Default motion is seven seconds, with deliberate anticipation, action and return. Preserve joint attachment, rigid props and supporting contact at every extreme. Describe small held-pose motion honestly.
- Run npm run compose, catalog, check, render and verify for changed assets, then npm run install-skill. Full revisions require full checks. Inspect actual rendered images; tests and scores cannot judge art.
- README is generated by scripts/catalog.mjs. The corpus index and installed skill must reflect the current format and files.
- Gallery and films are local deliverables. Do not imply publication or cloud rendering.
